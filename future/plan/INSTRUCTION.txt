【用法】平时只发这一个文件的全文：future/plan/0-自动调度-每次发这个.txt

本文件只做索引，不再承载规则（规则已拆分到下面三份自包含指令里）：

| 文件 | 什么时候由调度器调用 |
| --- | --- |
| 0-自动调度-每次发这个.txt | 平时发这个：判断该做哪件事并执行 |
| 00-一次性准备-最先发这个.txt | SETUP_DONE 未标记 DONE / ledger 缺失时 |
| 1-研究循环.txt | 有 pending 轮次且预算未用完时 |
| 2-最终检验.txt | 有冻结候选且最终窗口未使用时 |

状态只看 `future/docs/research/ledger.yaml`（机器可读、唯一权威）。
`STATE.md` 是给人看的摘要，`design-review.md` / `SETUP_DONE.md` / `R0.md` / `R1.md` 是过程记录。

改动约定：调参、改判据、换窗口一律视为违规；只允许"加信息"（补数据、加因子、加诊断），
并且每一步都要先在 `future/docs/research/rounds/<轮次>.md` 预登记再执行。
