## 1 诊断假设（为什么这一轮不是"试了再说"）

R2 是本项目第一次 primary 达标（IC NW t=2.25），但收益端两条 secondary 不过（bootstrap 下限 −5.78%、cost2x 年化 −1.40%）。
在决定"是否值得把品种扩到 20 个（R4）"之前，必须先回答三个可检验的结构性问题，否则 R4 只是拿试验预算赌运气：

1. **H3a（单年现象）**：若 `combined` 的 Rank IC 只在 2018-2019 显著、其余年份接近 0，则 R2 的 t=2.25 是
   局部样本效应，扩品种（R4）不会改变收益端的统计显著性，应直接进入 R5 或写结论。
2. **H3b（单腿现象）**：若收益几乎全部来自空头腿（或全部来自多头腿），说明这条 edge 本质是**方向性 beta**
   （2018-2019 的商品下行/上行段），而不是可对称使用的截面 alpha；此时扩品种只会放大 beta 暴露，
   不能提高 bootstrap 下限。
3. **H3c（cost 敏感的结构来源）**：若空头腿平均持有期更长/换手更低，则 cost2x 下"仅剩一条腿"能解释
   cost2x 年化转负（−1.40%）——那说明问题在**成本结构**而非信号，值得考虑限制换手，而不是扩品种。

以上三条都是对**已有产物**的分解，不新增参数、不改规则，因此不占试验预算（`plan/1-研究循环.txt` §四 R3 明写"纯诊断，不计试验"）。

## 6 分析口径（实现前写清，避免事后解释）

1. **逐年 IC**：与 `research_core.rank_ic` 完全同一算法（score 与 `z = forward_ret / (σ60·√H)` 的截面 Spearman，
   每日要求 ≥4 个有效品种），只是按自然年分组后再做 Newey-West（滞后 = H）。
2. **腿的远期收益检验**：多头腿每日取 `z` 的均值（>0 = 多头有效），空头腿每日取 `−z` 的均值（>0 = 空头有效），
   按年做 NW t。这是"腿有没有方向性信息"的直接检验，不依赖成交。
3. **腿内 IC**：在候选集内部再算一次 `score ↔ z` 的 Spearman（≥3 个品种），检验"选出来的腿内部还能不能再排序"。
4. **成交腿分解（仅 `combined`）**：用 `trades.csv` 按引擎口径重放（买开/卖开建仓、卖平/买平按均价实现、
   加仓更新均价），把已实现盈亏与手续费按腿、按平仓年份归类；期末未平仓按最后收盘盯市。
   **对账断言**：`20000 + 多头腿净额 + 空头腿净额` 必须等于 `equity_daily.csv` 的最后权益（误差 < 0.01 元），
   否则说明重放与引擎口径不一致，结果作废并记缺陷。
5. **`carry_only` 不做成交腿分解**：只有 2020-2023 的回填前产物，与 2018 窗口不可比，且重跑会产生
   新的收益数字（等于新试验）。只做 §6.1~§6.3 的信号层分解，表中显式标注。
